# Ranna — Recipe App

A mobile recipe app built with React Native and Expo for a university project.

## Features
- Browse and search thousands of recipes
- View ingredients and step-by-step instructions
- Save favourite recipes (persists after closing app)
- Browse by category
- Dark / Light mode toggle

## Tech Stack
- React Native (Expo, JavaScript)
- React Navigation v6 (Stack + Tab)
- Redux Toolkit
- Axios
- TheMealDB API (free, no key needed)
- AsyncStorage

## How to Run
1. Install Node.js from https://nodejs.org
2. Install Expo CLI: `npm install -g expo-cli`
3. Clone or download this project
4. Open terminal in the Ranna folder
5. Run: `npm install`
6. Run: `npx expo start`
7. Scan the QR code with Expo Go app on your phone
